# 觉醒者档案：新海风云

现代都市异能题材的单机 2D 俯视回合制 RPG，使用 **Godot 4.7.2 / GDScript / Compatibility** 制作。当前为非商用个人试玩原型，包含首章、章节前自由养成与第二章首版，完整十章故事仍在开发。

## 下载与启动

Windows 64 位试玩包在 [GitHub Releases](https://github.com/linbainian/xinhai-fengyun/releases)。下载 `XinhaiFengyun-preview-2026-10-02-windows-x64.zip`，完整解压后双击 `XinhaiFengyun.exe`。试玩包无需安装 Godot。

源码可克隆此仓库，或下载 Release 中的 `XinhaiFengyun-preview-2026-10-02-source.zip`。使用 **Godot 4.7.2 标准版**导入 `Game/project.godot`，按 **F5** 进入游戏；本项目不需要 .NET。

## 当前可玩内容

首章保留 **1月1日至3日**：与温让同行入学、检测、导师登台与拜师、苏挽颜委托、后山教学战及城区送件。角色登场与转场包含走位、镜头和淡入淡出。

**1月4日至14日**由玩家安排修炼、闲逛、委托与生活。每天有两次日间行动和一次可选夜间安排；十一种一次性奇遇包含图书馆、冰品店、冰雷对练和宿舍走廊。奇遇随闲逛自动入场，阅读对白后做选项；成长、关系与行囊带入后续章节。

**1月15日**触发第二章复筛，可继续参加正式社团、安排周日程、邀请三位开放同伴，并完成港口浅层裂隙两战与线索分流。当前可玩至港口 A/S 结算；M2的一小时连续试玩、完整技能树和最终平衡尚未验收。

战斗使用 **HP 与精神负荷 SL**，技能受到负荷、冷却、属性克制与临界突破影响。自由养成已接入五系选择、六维成长、技能熟练及安全 D→C 突破。

## 操作

| 按键 | 功能 |
|---|---|
| WASD / 方向键 | 移动 |
| E / 空格 | 接近人物或物件互动；空格也可推进对白 |
| Enter | 推进对白 |
| 数字键 | 选择当前显示的选项 |
| C | 打开 / 关闭日程与养成 |
| M / J | 地图 / 档案 |
| Esc | 菜单；演出中跳过并保留剧情结果 |
| F5 / F9 | 游戏内存档 / 读档 |
| F11 | 全屏 / 窗口 |
| 战斗 A / D / 1、2 | 攻击 / 防御 / 技能 |
| 战斗 Tab / B / H / L | 换目标 / 突破 / 提示 / 战斗记录 |

窗口可最大化，世界画面和 UI 分别适配客户区；探索与战斗保留整数像素缩放。中文界面使用系统字体，Windows 优先使用微软雅黑。

## 存档与重玩

存档位于 `%APPDATA%\Godot\app_userdata\觉醒者档案：新海风云\saves\`，与安装包位置分离，升级试玩包后仍可继续同版本存档。主槽文件为 `chapter1.json`，稳定节点自动保存，F5可手动保存。

已有首章完成归档时，标题会显示“首章完成档 · 从1月4日养成”。选择该入口前会另存当前养成 / 第二章进度，之后主槽跟随重玩流程；普通“继续游戏”保持原日期。新游戏使用同一主槽，请先备份需要保留的进度。

## 源码结构

```text
xinhai-fengyun/
├── README.md
├── AGENTS.md                  # 项目约定与当前实施状态
├── Game/
│   ├── project.godot           # Godot 工程入口
│   ├── export_presets.cfg     # Windows x64 导出预设
│   ├── scenes/                # 章节与战斗场景
│   ├── scripts/               # GDScript 逻辑
│   ├── data/                  # 章节、养成与战斗配表
│   ├── assets/                # 像素美术、来源记录与处理结果
│   ├── tests/                 # 规则、资源与窗口验收
│   ├── tools/                 # 台词导入、地图生成及打包工具
│   └── docs/                  # 验收、维护与预览
├── 策划与剧情/                 # 玩法和作者台词的编辑源
└── 世界观与人物设定/            # IP 设定与角色条目
```

策划目录与工程应保持同级，台词导入工具通过这个结构定位作者稿。玩法与剧情以策划目录为准，人物声音参考对应角色条目；改动应同步文档。`.godot/` 是引擎生成的缓存，不纳入源码。

开发、导出和验证命令见 [Game/README.md](Game/README.md)。
