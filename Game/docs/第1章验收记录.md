- 从新档跑到01-03送件结算和第1章结束页；标题继续游戏、五系选择、四导师任务与唯一拜师、三种委托态度、后山三战、社团首逛、宿舍夜谈、凌未央视频、林初夏照面和城市送件全部接通。

- 探索2倍相机、战斗3倍角色，运行精灵最近邻采样。战斗顶部状态、底部指令与紧凑预览，主战场高度680/1080（约63%）。L展开记录，鼠标可直接点击兔子，Esc优先收起记录。
- 自动稳定节点存档、F5/F9、主档损坏验证备份回退；恢复后保存不覆盖有效备份为损坏文件。章末可开档案并正常返回结束页。
- 迁移后追加分辨率适配：窗口、原生最大化与F11铺满客户区。像素世界单独整数缩放并调整可见范围，UI独立等比缩放和重新布局；姓名牌/兔子点击区域同步坐标变换，战斗阵型不被顶栏或底栏遮挡。
- 战斗读取真实行动全部目标，接入出招/命中/受击、实际伤害/克制/未命中、防御HP/SL及突破成功/失败；重试、重玩、换段、胜败、F11变化与退出清理。没有改变结算或随机数。
- 苏挽颜在四导师任一正式登记后主动走近，三种态度都接共通晚间收束；检测异能演出、温让同行与沈听澜评语顺序按稿接入。低血休息演出不额外治疗。旧存档落入新墙体会回安全入口，南侧超过旧地图高度的合法位置正常往返。
- 首日追加五段JRPG演出：校门同行、进入检测礼堂、检测后赴会场/四导师沿台阶登台、离场去展区、苏挽颜来访。角色实际四向行走、转身、镜头和淡入淡出，出场姓名条；演出1倍整数相机、结束恢复2倍，Esc或按钮跳过。实际运行动画见[第1章转场演出](第1章转场演出.md)。

本轮追加社团三个招新摊位与温让同行返寝，寝室/共用走廊分离，林初夏在楼道走来、交谈后离开。现16张首章地图、11段演出；新素材、操作和人物事件专项见[人物奇遇与宿舍场景验收](人物奇遇与宿舍场景验收.md)。
