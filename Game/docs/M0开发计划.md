## 本批交付

1. 保留原空工程的 Git 快照及 `project.godot` 备份。
2. 设置主场景、输入映射、2D Compatibility 渲染器、世界 nearest 过滤。
3. 48×48 占位角色四向移动，速度 192 世界像素/秒；同时按两个方向时保持一个轴，禁止斜向加速。
4. 1920×1152 测试空间、48 像素网格、四面边界和独立静态障碍。
5. 独立 Camera2D 跟随、整数位置、场景边界限制。
6. 世界固定 SubViewport 960×540；UI 独立 CanvasLayer，逻辑坐标 1920×1080。
7. 可重跑的引擎内移动/碰撞/相机/缩放验收与画面检查。
8. 保存一次通过验证的 M0 Git 提交。

## 渲染约定

- 根窗口的内容基准为 960×540，`canvas_items + keep + integer` 负责整数放大和黑边。
- 世界通过固定 960×540 的 SubViewport 输出；容器 nearest，世界启用 2D 变换与顶点像素吸附。
- UI 在根视口的独立 CanvasLayer 内，以 1920×1080 坐标设计，容器变换为 0.5。1080p 时根窗口 ×2，UI 实际按 1:1 渲染，世界像素 ×2。UI 不经过世界低分辨率纹理，也不受世界相机影响。
- 960×540 窗口时世界 ×1、UI ×0.5；1920×1080 时世界 ×2；3840×2160 时世界 ×4。
- 1280×720 默认窗口为世界 ×1，四周留黑边；这不是非整数拉伸。F11 可进入当前显示器的全屏模式。
- M0 使用 Windows 系统中文字体（Microsoft YaHei 优先），验证中文显示。正式可分发字体在 M1.5/M2 再选取并随工程附上授权。
- M0 角色方块与碰撞盒都为 48×48，原点在底边中心。正式人物的脚底碰撞尺寸在美术冒烟阶段结合身形确定。

## 美术管线约定

- 可使用网上授权素材和用户指定的 `generate2dmap`、`generate2dsprite`；选取每个资源时记录来源与授权。用户允许复用素材，优先于原策划“全自制”的预算假设。
- 学院探索地图优先采用可编辑 tile/object 层；地面、建筑/树木、交互物、碰撞与出生点分开。正式地图不以一张整场景图片替代运行时对象。
- 48×48 角色素材画布，底边中心锚点。四向行走可用统一 4×4 sheet；不同战斗动作分别生成、验收，再组装 atlas。
- 生成图保留提示词和原图；脚本只作抠图、拆帧、对齐与 QC。动作共用尺度，技能大特效另做，避免身体被缩小。
- 本批灰盒为明确确认的工程占位，不消耗正式地图/人物出图额度。
