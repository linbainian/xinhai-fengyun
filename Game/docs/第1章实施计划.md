# 第1章可玩流程实施计划

更新：2026-10-01。用户已授权生成统一像素美术、编写台词，并跑通从开始游戏到第1章结束；范围止于01-03首个送件任务完成和章节结束页。交接后的五项改进与检测礼堂重建已接入，详情见[首章美术与台词修订](首章美术与台词修订.md)。

1. 美术管线：生成林大四向行走、具名NPC、野兔、地表与独立场景物件；精修人物使用96×96源帧、48×48世界占位，处理硬透明边缘、共享尺度与锚点，记录提示词与QC。新增独立战斗效果和31个会场组件/地砖，重建外部大会场与入学检测礼堂。
2. 章节基础：标题、新游戏建档、存读档、可漫游地图、接近互动、中文对话与选择、当前目标和任务记录；新入口保留M0与M1独立场景。
3. 01-01：林大与温让同行到校门、进入检测礼堂，异能测试（读数延迟0.5秒、不解释）后一起赴大会场，四导师从侧边沿台阶登台介绍；四导师任务可逐一体验、回大会场正式拜师四选一；苏挽颜在导师展区走近交谈、委托与态度选择，随后共通晚间收束。五段演出及实际运行动画见[第1章转场演出](第1章转场演出.md)。
4. 01-02：社团招新首逛（正式入社留至第2章）、后山三段教程与胜败重试、苏挽颜数量异常伏笔；同寝夜谈、凌未央视频查寝、林初夏楼道照面。
5. 01-03：任务大厅刷学生证接首个帮忙任务、城市区域移动、管理局前台送文件；第1章结束与进度存档。
6. 验证：所有拜师分支、委托选择、整章顺序、重复交互/领奖、存读档、失败与返回、实际键鼠和三尺寸；原M0/M1回归。最终只提交本轮文件，保留用户已有M0改动。

剧情依据为当前剧情卷v0.3.6第1章、生活化修订台词稿及角色条目。温让开局好感80并进同伴档，凌未央好感40且是温让女友；苏挽颜在后山入口旁观。普通新生并非首次觉醒，不添加特殊身世。四导师任务和阵营加成采用游戏卷改编。作者稿通过安全导入器同步53个片段、221句正文与19项教程文案，导出默认只写Game/docs，不覆盖作者稿。

美术采用`tile_mode / layered_tilemap / interactive_scene_objects / explicit_collision / project-native Godot`；地表来自生成的可复用图块，建筑、家具、NPC、交互、出口与碰撞是独立节点和外置数据。不会把完整画面烘焙成不可编辑的探索地图。

初始系别先按推荐提供新游戏选择，默认念动力；人物像素服装为游戏美术设计，不改变条目中已有外貌。六维与派生属性未定映射继续保留显式战斗属性，拜师的已定直接加成单独应用。本章是可玩首章切片，不代表完整M2的所有系统与一小时体验判据已完成。
