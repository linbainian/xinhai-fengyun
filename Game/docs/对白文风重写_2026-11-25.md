## 方法

- 按片段切成 11 个重写块，逐块交写作子代理，共用同一份作业单（硬性格式＋文风禁词＋人物声口）。
- 子代理只覆盖块文件；主代理按清单重新拼回作者稿，并做结构校验后再落盘。
- 校验：片段 ID 集合一致；演出注与系统提示逐行一致；未新增具名说话人（第2章仅新增 3 段 `旁白` 动作）；单行最长 69 字（上限 110）；禁用词与「像……一样」「不是A，是B」「风停了一瞬」等套式扫描为 0；旁白无第二人称「你」。
