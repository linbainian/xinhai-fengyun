# M0 验收记录

验收日期：2026-09-30。验收环境：本地 Windows、Godot 4.7.2、Compatibility / OpenGL 3.3，NVIDIA GeForce RTX 3050。

## 结果

**M0 工程灰盒通过。** 已通过 Godot MCP 打开编辑器并启动主场景，启动后的调试输出为 `errors: []`。

| 项目 | 验证方法 | 结果 |
|---|---|---|
| 资源导入与主场景运行 | Godot `--import`、运行主场景、MCP 启动 | 通过，无脚本/场景错误 |
| 四向移动与速度 | 输入动作驱动真实物理步进，四方向分别运行 60 个物理帧 | 通过，192 世界像素/秒 |
| 双方向同时按下 | 同时输入上/右，测量位置变化 | 通过，仅沿一个轴移动，无加速 |
| 四面围墙 | 向每面围墙持续移动并测量停止位置 | 通过，不穿墙 |
| 内部障碍 | 从花坛四个侧面分别撞击 | 通过，碰撞与可见边界一致 |
| 障碍形状独立 | 校验 12 个障碍的尺寸与 Resource 实例身份 | 通过，调整一个障碍不会改变另一个 |
| 相机跟随与边界 | 校验相机整数位置、屏幕中心和地图边界 | 通过 |
| R / F3 | 向引擎注入实际 InputEventKey | 通过，回到出生点、隐藏/恢复网格和诊断 |
| nearest 与像素吸附 | 实例配置 + 实际渲染像素检查 | 通过 |
| 世界/UI 分离 | 1080p 图像检查：世界每个 2×2 像素块相同，UI 字形在块内有更细的边缘 | 通过 |
| F11 | 图形环境内键盘事件驱动两次切换 | 通过，进入全屏后恢复窗口模式 |
| 中文显示 | 亲自检视 960×540 与 1920×1080 渲染图 | 中文可读，无缺字或文字截断 |

引擎内移动/物理/配置验收 **55/55 通过**。画面验收及 F11 检查也通过。

## 实际窗口尺寸与输出

以下为引擎完成窗口调整之后的实际值，已检查实际窗口等于请求尺寸。

| 实际窗口 | 世界视口 | 世界放大 | UI 坐标缩放 | 渲染内容图 |
|---|---|---|---|---|
| 960×540 | 960×540 | ×1 | ×0.5 | 960×540 |
| 1280×720 | 960×540 | ×1 | ×0.5 | 960×540，窗口左右各留 160、上下各留 90 像素 |
| 1920×1080 | 960×540 | ×2 | ×1 | 1920×1080 |

渲染内容图来自 Godot 的视口纹理，不包含操作系统窗口边框，也不包含整数缩放留下的外侧黑边。4K 的 ×4 是工程设置支持的比例，本次没有实测 4K 显示器。
