# 游戏对白与剧情衔接修订 · 2026-10-02

> 后续修订：本篇的范围与验收记录对应v0.3.10。用户指出其中白沐瑶初识话量和接梗失当，现已按v0.3.11改为点头、简短道谢；下面的对白例已替换为现稿。当前奇遇为19片段/101句，最新验证见[白沐瑶初识对白修订](白沐瑶初识对白修订.md)。

本轮已重写当前可玩的首章、第二章及十一种养成奇遇，导入运行数据，并同步作者稿、剧情卷 v0.3.10 和实施补充。重点是人物正在办自己的事、主角会追问、选择有回应、关系从共同经历里积累。

## 参考与写法

《侠客风云传》的官方介绍将养成、交友及剧情相连；《逸剑风云决》介绍结交同伴和选择带来的变化；《大侠立志传》强调初入江湖者在市井里的行动与际遇。本轮据此安排交流过程：一起收行李、找路、完成委托，才有后面的熟悉与关照。参考来源为公开官方介绍，本项目台词按现代都市学院人物另行创作。[侠客官方介绍](https://wulin.fhyx.com/)、[逸剑官方介绍](https://store.steampowered.com/app/1876890/Wandering_Sword/?l=schinese)、[大侠官方介绍](https://store.steampowered.com/app/1948980/?l=schinese)。

人物声音依据对应世界书条目；分支、日期和收益依据游戏策划。温让会损人，也会同行、提醒出门带证；苏挽颜和林大有从小住隔壁的生活习惯；江北辰少言，接过包子后仍问多少钱；林初夏在走廊收东西、抄活动表；韩烛忙着核名单和巡逻，秦妖妖盯装备与路况。老师各按专业办事，窗口人员有收件与登记流程。

删去缺少上下文的半句话、抒情兜底和整齐的道理句。旁白照用户指定方式自然省略主角动作的“你/你们”，交代关系时保留必要指代。问好与寒暄随场合安排，正在同行或办事的人直接接眼前的话。

原六奇遇新增12段选择收尾：归还/核页、步法/护具、采叶/记位置、归还/修箱、买书/翻目录、搬货/核单。选前不提前替玩家完成承诺，选后人物接话或简短交代动作，最后显示成长收益。

三位可入队同伴各新增入队、离队回应，共6段。离队对象确实在队伍时才播对应告别；未在队伍的对象继续使用通用提示。

图书馆对白例在v0.3.11按用户的人设纠偏替换如下，初见时不主动攀谈：

> 旁白：把两本书放上借阅台。白沐瑶点了下头。  
> 白沐瑶：谢谢。

校园日常不会把帮发传单当作已经发生。午休场景兼容对练的两个选择，避免只在“照实说”分支出现的加练约定被共通段当作已知。苏挽颜三种回应继续共用已收到的后山路线与半价券。

## 接入与维护

作者编辑源：

- [第1章实装台词脚本](../../策划与剧情/第1章实装台词脚本_v0.1.md)
- [第2章实装台词脚本](../../策划与剧情/第2章实装台词脚本_v0.1.md)
- [养成人物奇遇实装台词](../../策划与剧情/养成人物奇遇实装台词_v0.1.md)

沿用三个 `import_*_script.py --apply` 导入器，先备份再写JSON。首章导出器只更新 `Game/docs` 可读副本。新增收尾由 `data/cultivation/events.json` 原六事件选项的 `dialogue` 字段引用；正文放在第二章作者稿末尾“选择后的人物回应”。既有人物奇遇仍由独立奇遇作者稿维护。

`ChapterCultivation._reply()` 增加纯展示标记 `remark_after_dialogue`。`ChapterOne.present()` 据此将成长记录排在人物对白后面；缺省顺序仍保留沈听澜先评语、再邀请的安排。同伴回应只改变选用的片段ID。

程序事件仍保留检测0.5秒延迟、下午大会场转场、后山路线确认；低血收尾继续删去主角额外问句。原地图与演出JSON保持原样，12段新收尾为文本段。十一事件的日期、条件、选项顺序、数值、一次性结算规则保持，外层存档仍是 `chapter1.1`。
