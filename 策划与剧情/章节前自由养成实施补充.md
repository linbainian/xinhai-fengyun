## 时间与入口

首章结束页按钮改为“进入自由养成 · 1月4日”，先归档首章，再进入宿舍的养成介绍。玩家有01-04—01-14共11天、22个日间行动和11个可选夜间安排。日间分上午/下午，各1行动；完成两次日间行动后进入夜间。移动、交谈、地图往返和送件交接不额外扣时段。

按C或世界画面“日程与养成”打开原生Godot面板，四个分页为修炼、闲逛、委托、生活。左侧显示角色、导师、HP/SL、觉醒度、六维和战斗派生值；中部是行动及收益、两招独立熟练度和最近成长；右侧为日历、剧情日期、行动余额、当前发现、委托、关系及行囊。

休息可放弃当天未用行动。睡到01-15时，日历切入复筛阶段，自动演出学生证通知；未完成复筛前不能继续睡觉或预排。七天课表按正常行动执行课程和实战训练，已登记社团时部分下午改为社团活动，夜间不代做安排；遇01-15会提前停下，并显示实际推进天数。复筛后继续使用同一套日历、养成状态、物品与技能。02-01开放已有港口★★任务。

新档周起点为01-04，每7天刷新委托并结算贡献2（第一轮01-11）。旧版第二章存档保留其01-15周起点，避免改变旧档日期、周记录和已完成任务。正式社团登记可在自由养成时选择，也可留到复筛后，不强制加入；开放入队仍在复筛后。

## 修炼与生活配表

每次日间行动只消耗1点。原始六维均10、感知12；面板加上已选择导师的既定属性奖励，存档保存原始成长值，避免读档重复加成。原始六维上限40。

| 行动 | 永久收益 | 觉醒度 / SL |
|---|---|---|
| 实战基本功 | 力量+1、主攻技能熟练+4 | +3 / +5 |
| 灵能运用 | 精神+1、两招熟练各+3 | +6 / +8 |
| 体能锻炼 | 体质+1、敏捷+1 | +2 / +3 |
| 静心观息 | 意志+1、感知+1 | +2 / −10 |
| 学院课程 | 学业+5、课业次数+1 | +2 / 0 |
| 社团活动 | 群攻熟练+2、温让好感+1、社团次数+1 | +3 / 0 |
| 调息休整 | 恢复主角HP | 0 / −20 |
| 宿舍夜读（1夜间） | 学业+5 | 0 / −10 |
| 温让夜谈（1夜间） | 温让好感+5 | 0 / −5 |

两招熟练各自0—100，达到20/50/80时技能伤害倍率分别变为1.05/1.10/1.15。80熟练的技能变式与完整技能树留后续，本轮没有额外主动技能。训练次数保留旧版攻击加成上限6，用于旧档连续性；具体修炼同时提升六维与技能。

当前派生映射是可调原型，并非最终完整六维公式。仅作用于首章之后的港口战斗，M1灰盒和首章教程沿用既定配表：

| 项目 | 原型映射 |
|---|---|
| HP上限 | 首章基础220 × 唐半夏已定1.1奖励（如适用） + 体质成长×3 |
| 攻击 | 基础24 + min(训练次数,6) + 力量成长×0.5 |
| 防御 | 基础12 + 体质成长×0.25 |
| 速度 | 基础16 + floor(敏捷成长×0.5) |
| 技能威力 | 原技能倍率 × (1+精神成长×0.01) × 该招熟练倍率 |
| 技能负荷 | 原SL消耗 × 导师已定倍率 × max(0.7,1−意志成长×0.01)，按既有战斗规则取整 |
| 感知 | 将成长后的感知传入既有命中公式；导师奖励只应用一次 |

“成长”指相对初始原始属性的增加值。导师AGI/SPI/WIL/CON+3和既定HP/冷却/负荷奖励继续传入角色定义。仅有HP、SL两条资源，没有MP。体质提升先增加上限，睡眠/休整再恢复新增缺口。

觉醒度100、尚为D级时，在安全环境消耗1行动尝试D→C突破，基础成功率95%。成功永久C级/行动等级3，HP恢复、SL清零、觉醒度归0；失败保留D级/等级2，觉醒度65、HP−10（至少1）、SL+20，获得1份感悟笔记。结果以存档中的尝试次数确定，重新读取同一检查点不能重抽。当前只开放D→C；临阵突破仍是原有单场机制。

## 委托、存档与维护

器材整理、档案誊抄每周各一次，均消耗1行动，奖励80元/贡献1，誊抄另加学业3。城区送件每周一次，接取消耗1行动，需M去管理局服务大厅，靠近受理员按E交件才发150元/贡献2。送件可以跨日、跨周和跨复筛保留；旧单记在接取周，下周可再接一份。面板与原任务板共用同一个完成账本，不能重复领取。

外层存档仍为 `chapter1.1`；日历升级为 `chapter2-prototype.2`，养成字段 `cultivation.1`。支持首章旧档；已经到第二章的旧档保持当前剧情日期和路线，补上初始成长档案，并迁移本周帮忙记录，继续用C面板。旧档不自动倒退到01-04；标题在存在归档时显示“首章完成档 · 从1月4日养成”，可直接进入11天新流程。选择重玩前将现有养成/第二章主档另存 `chapter1-before-cultivation-replay.json`，归档失败不切换，此后主槽跟随选中的新流程；没有归档则从新游戏进入。

配表：`Game/data/cultivation/settings.json`、`events.json`。逻辑：`chapter_cultivation.gd`、`chapter_two_calendar.gd`、`chapter_two_story.gd`。面板：`chapter_cultivation_panel.gd`，继续使用世界960×540、UI1920×1080的分层自适应。第二章作者稿当前113片段/394句（含自由养成介绍、原六事件与相关生活对白），通过原导入器先备份再写运行数据；没有更换或移动美术引用。
