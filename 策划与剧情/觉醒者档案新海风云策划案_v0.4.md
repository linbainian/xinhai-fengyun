## 0. 一句话定位

**一款"都市异能版武侠人生"回合制 JRPG**：白天在觉醒者学院上课、修炼、结交伙伴，夜晚与裂隙、黑市、阴谋周旋——把《侠客风云传》的日历养成、《金庸群侠传》的开放江湖、《逸剑风云决》的像素回合制战斗，装进"觉醒历 22 年"的异能都市。

### 0.1 与参考作品的对应关系（抄"骨"不抄"皮"）

| 参考作品 | 借鉴的机制骨架 | 本作的异能化转译 |
|---|---|---|
| 侠客风云传 | 日历制人生养成、属性修炼、拜师、事件日程 | 觉醒历日程系统、觉醒度修炼、四大导师拜山、学院年度节点 |
| 金庸群侠传 | 开放世界、多势力声望、自由善恶路线、多结局、任意 NPC 可结伴闯江湖 | 新海市六区开放探索、四势力声望、多结局主线、开放入队系统 |
| 逸剑风云决 | 2D 像素呈现、经典指令式回合战斗、武学搭配 | 2D 像素都市异能、指令回合制、五系技能 Build |

### 0.2 内容改编声明（原卡 → 游戏）

- 原卡的 MVU 变量系统 → 游戏存档与状态机；
- 原卡的叙事型 DC 检定 → 回合制数值公式（见第 5 章）；
- 原卡 147 名角色 → 精选约 **20 名**活跃 NPC（单人全自制美术产能约束；开放入队：其中具战斗能力者均可邀约，见 §8.4）；
- 原卡中的成人向内容**全部剔除**；
- 玩家主角固定为"国立新海觉醒者学院大一新生"，开局 = 觉醒历 22 年 01 月 01 日入学日（与原卡锚点一致）。

## 1. 设计支柱（Design Pillars）

1. **代价感**：异能不是免费的——精神负荷是唯一的"施法资源"，也是唯一的"翻车风险"，"要不要赌一把"是每一场战斗的核心决策。
2. **人生感**：一年学年的日程循环，玩家自己决定今天修炼、上课、接任务还是 social，时间花在哪，实力和关系就长在哪。
3. **越级的浪漫**：等级压制真实存在（跨级打高级敌人极难），但克制、地形、临阵突破给了"以下克上"的操作空间与戏剧时刻。
4. **都市即江湖**：管理局是"官府"，互助会是"绿林"，家族是"世家"，渊蚀会是"魔教"——武侠的社会结构翻译成异能都市。
5. **江湖不设限**：没有"官方指定队友"——你在新海市建立的每一段关系，都可能变成并肩作战的战力（金群侠传式自由结伴）。

## 2. 世界观与舞台（沿用原卡设定，摘要）

- **时代**：觉醒历 22 年。觉醒潮后 21 年，异能公开化，觉醒者上热搜、当明星，异能竞技是顶流综艺。
- **舞台**：新海市（异能首都）六区——学院区 / 中央商务区 / 龙湾富人区 / 旧城地下街 / 港口工业区 / 觉醒者医疗区。
- **力量体系**：F~SSS 九级；五大系别（念动力 / 元素 / 强化 / 精神 / 特殊）+ 系别克制环。
- **势力**：异能管理局（官方）、觉醒者学院（母校）、暮光互助会（灰色江湖）、渊蚀会（邪教反派）、古血脉家族联盟（世家）。
- **暗线**：觉醒潮真相（极光疑与"深渊"有关，教主姜无咎可能是起因本身）——全游戏最高级别悬念，逐层拼图解锁。

## 3. 核心玩法循环（三层嵌套）

### 3.1 宏观循环（学年，约 15~25 小时一周目）

```
入学/拜山 → 日常修炼&上课 → 接任务/下裂隙 → 资源反哺养成
    ↑                                          ↓
    ←—— 年度节点（天榜结算/学院杯/年度实战考核）←——
```

### 3.2 中观循环（周，游戏内 7 天为一周期）

| 行动 | 产出 | 消耗 |
|---|---|---|
| 修炼（选地点） | 觉醒度、技能熟练度 | 行动点 |
| 上课/自习 | 学业值、属性小加成 | 行动点（缺席有代价） |
| 任务大厅 | 资金、贡献点、声望 | 行动点 |
| 裂隙探索 | 结晶、素材、觉醒度（战斗经验） | 行动点+补给 |
| 社交/约会 | 好感度、情报、支线解锁 | 行动点 |
| 休息 | 精神负荷回落、恢复 | 行动点 |

每周结算：**任务板刷新（每 7 天）**、同伴日程变动、随机事件抽取（3~5 张事件池）。

### 3.3 微观循环（战斗，单场 3~5 分钟）

试探（观察敌方系别）→ 交火（技能/克制/负荷管理）→ 转折（连携技 or 临阵突破 or 失控）→ 决胜。

**核心验证问题**（先想测法再做玩法）：玩家一场战斗中是否至少做出 3 次"有信息支撑的决策"（换目标 / 压负荷 / 放连携 / 赌突破）？做不到就说明战斗深度不足。

## 4. 日程与时间系统（侠客风云传式，本作脊柱）

### 4.1 时间结构

| 层级 | 粒度 | 说明 |
|---|---|---|
| 年 | 觉醒历自然年 | 学年 = 自然年，每年 01-01 升年级 |
| 周 | 7 天 | 任务板刷新、周结算、NPC 周程的基本单位 |
| 日 | 上午 / 下午 / 夜间 | 每日 2 行动点 + 夜间 1 自由时段（社交/夜探，部分区域夜间才开放） |

### 4.2 觉醒历 22 年年度节点（第一年主线节拍）

| 月份 | 节点 | 玩法作用 |
|---|---|---|
| 01 月 | 入学日：异能测试 + 拜山（四大导师双向选择） | 教学关 + Build 分支起点 |
| 03 月 | 觉醒潮纪念日公祭 | 世界观叙事节点，暗线线索① |
| 04 月 | 天榜季度结算 | 排名反馈（主角冲天才榜） |
| 06 月 | 期中裂隙实训（校外） | 首个中型裂隙副本（团本） |
| 07 月 | 天榜季度结算 | — |
| 08 月 | 暑期自由活动期（寒暑假已废除，但课业减半） | 高自由探索窗口 |
| 10 月 | 天榜季度结算 + **学院杯·年度年级大比** | 年度竞技高潮（强制参赛） |
| 11-12 月 | **年度实战考核** | 毕业前置大考 + 第二幕高潮 |
| 12 月末 | 年度结算 → 升年级 | 存档年检（属性/好感/声望结算） |

> 原卡仅锚定入学日与考核/学院杯的存在性，具体月份为设计建议，可调。

### 4.3 灵能浓度（修炼效率的地理差异）

| 区域 | 浓度档位 | 恢复 | 修炼效率 | 战斗威力 |
|---|---|---|---|---|
| 灵能荒漠（屏蔽室/封印区） | 0-19 | ×0.3 | 无法自然增长 | -30% |
| 低灵能区（郊外/旧城边缘） | 20-39 | ×0.7 | ×0.5 | -10% |
| 普通区（市区默认 50） | 40-59 | ×1.0 | ×1.0 | 标准 |
| 高灵能区（修炼塔 4 层/裂隙周边） | 60-79 | ×1.5 | ×1.5 | +15% |
| 灵能富集区（修炼塔 7 层/裂隙中心/龙湾灵脉） | 80-100 | ×2.0 | ×2.0 | +20% |

设计意图：修炼塔逐层解锁 = "练功场"进度条；去裂隙修炼高收益高风险（精神负荷积累 +20%~50%）。

## 5. 战斗系统（核心交付物·指令式回合制）

### 5.1 基础框架

- **队伍**：主角 + 最多 3 名入队同伴（开放入队，见 §8.4），前后排两列（前排近战/承伤，后排远程/辅助）；
- **敌人**：1~6 体，可混编不同系别（逼玩家做目标选择）；
- **回合流程**：按速度（SPD）排序行动 → 指令菜单【攻击 / 技能 / 移动（换排）/ 道具 / 防御 / 突破】→ 结算 → 下一回合；
- **先攻**：SPD 高者先动；同速掷 1d6 决定（保留原卡 d10 骰子的"波动感"于伤害公式中）。

### 5.2 角色属性（六维 + 两条资源）

| 属性 | 对应系别倾向 | 作用 |
|---|---|---|
| 力量 STR | 强化系 | 物理攻击、负重 |
| 敏捷 AGI | 速度强化 | 速度、闪避、行动顺序 |
| 体质 CON | 防御强化 | 生命上限、抗侵蚀 |
| 精神 SPI | 元素/念动力 | 异能威力、技能冷却缩减 |
| 感知 PER | 侦查/预知 | 命中、暴击、先手侦测 |
| 意志 WIL | 精神系 | 精神负荷抗性（降低 SL 增幅）、控制抵抗 |

**两条资源（v0.4 精简）**：
- **生命 HP**：归零倒地；
- **精神负荷 SL（0-100）**：本作**唯一**的异能资源——既是"施法成本"（放技能就涨），也是"翻车风险"（涨过阈值就出事）。没有蓝条管理，只有火候管理。

> 设计说明：删除 MP 后，战斗决策从"油量够不够"变成"体温烧到几度了"——玩家时刻在 SL 收益曲线上做风险决策，配合技能冷却（§5.3）防止无脑连放最强技能。系统更精简，也更好配表（个人项目友好）。

### 5.3 精神负荷与觉醒失控（代价法则的战斗化 · v0.4 重构）

> M1-B/C 原型的技能冷却时点、负荷阶梯累计、偏离与失控口径见 [M1-B/C 战斗灰盒实施补充](M1-BC战斗灰盒实施补充.md)。

**SL 增幅规则**（替代 MP 消耗）：

| 行为 | SL 增幅 | 备注 |
|---|---|---|
| 普通攻击 | +0 | 无代价 |
| 常规技能 | +3~5 | 弱技能可能 +2 |
| 强力技能 | +8~12 | 高倍率/大 AOE |
| 越级技能 | +12~18 | 威力大但烫手 |
| 连续施放（同回合第 2 个技能起） | 额外 +5 | 防连发 |
| 双系技能 | 增幅 ×2 | — |
| 克制命中 | -2（负增幅，回落） | 打出克制有微弱"顺势"降压 |

**技能冷却（MP 的替代节制机制）**：
- 强力技能带冷却回合（弱 1 / 中 2~3 / 强 4~5），用 CD 防止单技能循环；
- 冷却受精神 SPI 影响小幅缩减（SPI 高 = 灵能运用更娴熟）。

**SL 阈值阶梯**：

| 负荷区间 | 效果 |
|---|---|
| 0-49 | 正常 |
| 50-69 | 轻度透支：伤害与命中 -10% |
| 70-84 | 中度透支：伤害与命中 -20%，命中类判定额外 -15% |
| 85-99 | 重度透支：每回合 15% 概率技能偏离（随机目标） |
| 100 | **觉醒失控**：3 回合无法操作并随机攻击敌我，失控期间自身伤害 +50%，结束后 SL 回落至 40 |

**SL 回落手段**：
- 防御指令 = 主动"降压"回合（SL -15，HP 回复 10%）；
- 治愈系同伴技能加速 SL 回落（-5~15/次）；
- 战斗外：休息/睡眠自然回落（探索层与日程层共用同一 SL 池——今天战斗烧太狠，晚上就得休息，行动点经济联动）。

- 失控不是纯惩罚：失控期间伤害提升 50%，高手可以"算计失控"（高风险流派，剧情中也用于戏剧高潮）。

### 5.4 伤害与命中公式（结构定死，系数待原型验证）

> M1-A 原型的伤害取整、最低伤害、同速重掷、重试及测试配表口径见 [M1-A 战斗灰盒实施补充](M1-A战斗灰盒实施补充.md)。该补充只覆盖首批沙盒，技能/SL 阈值/突破等仍分批接入。

```
最终伤害 = (攻击力 × 技能倍率 + 2d10) × 克制修正 × 环境修正 × 等级压制修正 − 防御 × 0.5
命中判定 = 基础命中% + 感知差 × 2 − 目标闪避%（简化为百分比，不做骰表）
```

| 修正项 | 取值 | 来源 |
|---|---|---|
| 克制修正 | 克制 ×1.2 ／ 被克 ×0.8 | 五系克制环（下表） |
| 环境修正 | ×0.7 ~ ×1.2 | 灵能浓度、天气（雨→水系+、雷雨→雷系+） |
| 等级压制修正 | 差 1 级 ×0.85／×1.18；差 2 级 ×0.7／×1.4；差 3 级以上 ×0.55／×1.6 | 原卡"DC 等级压制"的连续化 |

**五系克制环**（原卡设定直接沿用）：

```
念动力 → 强化 → 精神 → 元素 → 念动力（箭头 = 克制）
特殊系：不参与克制环，靠功能性（治愈/空间/召唤/言灵）立足
```

### 5.5 临阵突破（招牌机制，战斗的"翻盘赌"）

- 每名角色战斗中有**临界槽（0-100）**：受击 +8~12、打出克制 +15、使用技能 +5；
- 临界槽满 100 → 指令菜单解锁【突破】：
  - 消耗 1 整回合，播放突破演出；
  - 基础成功率 60%，连续战斗/低血量等修正 ±10~20%（面板明示，不藏概率）；
  - **成功**：本场战斗全属性 ×1.3、**SL 清零 + HP 回复 50%**（绝境翻盘的完整闭环）（等级真正的提升在战斗外结算）；
  - **失败**：SL +25、临界槽回落 50，1 回合虚弱（输出减半）；
- 保底：同场战斗每次失败后再尝试 +15%（最多两次）。

> M1-C 原型的自身行动口径、临界增幅、成功回复上限、虚弱计时与保底验证见 [M1-B/C 战斗灰盒实施补充](M1-BC战斗灰盒实施补充.md)。低血/连续战额外成功率幅度暂为0，待函数定稿后接入。

### 5.6 连携技与协力（系别组合模板制）

- 连携技由**双方系别组合**决定，不绑定具体角色：如「元素+念动力 → 合击·环流风暴」「强化+治愈 → 圣盾猛攻」「精神+任意 → 意念共鸣」等，共设计 **12~15 个系别组合模板**；
- 解锁条件：两名入队角色互相好感 ≥ 51（信任期，双向判定）；
- 连携无视部分等级压制修正（以下克上的正规手段之一）；
- 消耗：双方各 +15 SL，冷却 3 回合（v0.4：无 MP，改为纯 SL 成本 + CD）；
- **专属连携彩蛋**（低成本高记忆点）：仅 3~4 对高人气固定组合（如主角×青梅、主角×死党）有专属演出与命名连携，覆盖通用模板之上。

### 5.7 战斗节奏基线（验收标准，数值待原型验证）

| 场景 | 时长 | 参考难度 |
|---|---|---|
| 野怪遭遇 | 1-2 分钟 | 无脑速胜可 |
| 精英/悬赏任务目标 | 3-5 分钟 | 需要目标选择与负荷管理 |
| Boss（剧情战） | 6-10 分钟 | 必须用克制/连携/突破中至少两项 |

## 6. 养成系统

### 6.1 觉醒度与等级突破（原卡核心循环的直译）

- 觉醒度 = 经验进度条（0-100），修炼/战斗/剧情均积累；
- 满 100 进入"突破临界"状态 → 在安全环境（修炼塔/宿舍）消耗 1 行动点尝试突破；
- 突破成功率（原卡数值沿用）：

| 突破 | 基础成功率 | 修正示例 |
|---|---|---|
| E→D ／ D→C | 95% | 几乎必成 |
| C→B | 65% | 灵能浓度 ≥80 +10%；导师指导 +10%；结晶/药剂 +5~15%（合计上限 +20%） |
| B→A | 45% | 精神负荷 70+ 则 -20%；刚经历战斗（HP 未满）-10% |
| A→S | 25% | 失败保底：每次失败 +5%，成功后重置 |
| S→SS | 15% | —— |

- 失败后果：觉醒度回落至 50-75、SL +20、HP -10、1 回合虚弱；**必掉落一条"感悟线索"**（指向可执行的变强途径：找某导师/去某地/缺某道具）——失败推进剧情，不是纯损失；
- 一周目等级天花板设计为 A 级（对应原卡大三顶尖水平），S 级留给终章剧情战与二周目。

### 6.2 技能与熟练度

- 每个技能独立熟练度（0-100）：<20 无加成 → 20-49 伤害 +5% → 50-79 +10% → 80+ +15% 并解锁技能变种；
- 技能槽：每人装备 6 个主动 + 3 个被动（逸剑式搭配深度）；
- 技能来源：导师传授（拜山分支）、裂隙掉落图鉴、同伴切磋（开放入队系统的乘法价值：邀请不同系的伙伴=学到不同系技能）、家族/势力声望商店。

### 7.2 异界裂隙（副本系统 = Roguelite 轻量化）

**入口生成规则**（沿用原卡生成器，做进游戏）：
- 每月刷新 2-5 个小型 + 概率中型裂隙（世界地图标记，先到先得）；
- 副本构成 = 地形(1d6) × 威胁(1d6) × 宝物(1d6)：

| 地形（1d6） | 特征 |
|---|---|
| 紫雾荒原 | 视野差，远程减益 |
| 悬浮岩廊 | 坠落即死区，跳跃玩法 |
| 破碎都市 | 可躲避/伏击/搜刮 |
| 晶化森林 | 高价值采集+高危险 |
| 倒悬河域 | 重力混乱，速度类技能变化 |
| 深渊边缘 | SL 持续累积，宝物品质最高 |

- 结构：浅层（黄区，2-3 场战斗+采集）→ 深层（红区，守关异兽/Boss）；
- **灵能风暴**：全场倒计时事件，风暴来临前必须找到掩体（探索层的紧张感来源）；
- 稳定型裂隙 = 周刷新可重复刷（farm 点，势力争夺剧情素材）；不稳定型 = 一次性高收益；
- 时间流速彩蛋：出来后游戏内时间随机偏移 ±1 天（原卡设定，做成惊喜事件）。

### 7.3 任务系统（学院任务大厅 · JRPG 冒险公会机制）

**定位**：玩家接取任务的核心入口 = 学院任务大厅（原卡"学院任务体系"直译：任务大厅 / 贡献点 / 资源兑换处）。任务由**学院统一发布**，同时代发管理局、商会、市民与校内社团的委托——参考 JRPG 冒险公会：一块任务板、星级门槛、每周刷新、先到先得。**悬赏只是任务类型之一**，不再是独立系统。

**任务类型**：

| 类型 | 内容示例 | 刷新 | 定位 |
|---|---|---|---|
| 悬赏任务 | 追捕通缉犯、镇压失控觉醒者、清剿裂隙异兽 | 每周刷新 | 战斗向主力，高收益高风险 |
| 帮忙任务 | 跑腿送件、护送同学、寻物、采集、社团支援、照顾实训异兽 | 每周刷新 | 日常向，低门槛，探索与社交入口 |
| 外包委托 | 管理局（巡逻/情报整理）、商会（货物护送）、市民（琐事） | 每周随机池 | 世界观窗口，各势力声望入口 |
| 任务链 | 同一 NPC/同一悬念串起 3-5 段连续任务（如"老张头的废品站"） | 固定 | 支线叙事载体，终点给稀有奖励 |
| 剧情任务 | 主线节点、同伴专属任务 | 节点触发 | 推进三幕主线，不可放弃 |

**任务星级（难度与门槛）**：

| 星级 | 推荐等级 | 示例 |
|---|---|---|
| ★ | E~D | 给食堂后厨搬运灵能食材、把文件送到管理局前台 |
| ★★ | D~C | 护送商会货车穿越旧城、采集裂隙浅层晶化树脂 |
| ★★★ | C~B | 讨伐 C 级通缉犯、中型裂隙浅区清剿 |
| ★★★★ | B~A | 镇压 B 级觉醒失控、黄金级悬赏目标 |
| ★★★★★ | A+ | 剧情大事件专用（学院杯安保、年度实战考核相关） |

**冒险公会式规则**：
- **接取上限**：同时挂起 3 个任务；可主动放弃（小额贡献点惩罚）；
- **门槛校验**：星级对应等级硬门槛；部分任务带系别/导师推荐标签（满足标签解锁隐藏奖励条件）；
- **限量名额**：热门任务限量接取，每周刷新时被抢走的任务显示"已被接取"（世界鲜活度）；
- **任务评价**：按耗时/伤亡/额外目标给 S/A/B/C 评价，奖励系数 ×1.2 / ×1.0 / ×0.8 / ×0.6；
- **重复任务**：采集、巡逻类可重复接取，收益递减（防无脑刷）；
- **奖励构成**：资金 + 贡献点（主产出）+ 结晶/素材/装备（概率）+ 势力声望 + 指定 NPC 好感。

**违约与堕落面**：悬赏任务中伤害普通人、私刑、私吞缴获 → 通缉热度上升 → 追猎剧情线（金群侠传式邪路线入口，保留原卡"通缉热度"变量）。

## 8. 剧情结构（三幕 + 多结局）

### 8.1 主线骨架

| 幕 | 时间 | 核心事件 | 对应玩法解锁 |
|---|---|---|---|
| 第一幕·入学 | 01-03 月 | 入学测试、拜山、新生筛查、首次小裂隙、觉醒潮纪念日异变 | 教学+全部基础系统 |
| 第二幕·暗流 | 04-09 月 | 渊蚀会渗透校园、血鸦小队现身、人为觉醒实验线索、学院杯 | 中型裂隙、连携、势力声望玩法 |
| 第三幕·真相 | 10-12 月 | 年度实战考核被劫持 → 大型裂隙事件 → 觉醒潮真相碎片 → 终战 | 高级技能、终局分支 |

### 8.2 暗线设计（原卡"觉醒潮真相"的拼图式叙事）

- 真相碎片分散在：姜无咎（不轻易见面）、老张头（废品站支线）、苏老太君（家族线）、管理局深层档案（管理局路线）；
- 每块碎片 = 一条独立支线的终点；收集数量决定终章可选项，**不集齐也有默认结局**（不逼全收集）。

### 8.3 结局矩阵（周目重玩价值）

- 势营倾向（管理局 / 互助会 / 家族 / 独立）× 真相处理（公开 / 封锁 / 利用）≥ 6 结局 + 同伴个人结局（好感至诚期触发）；
- 二周目继承：等级与技能熟练度（软继承，压数值）、图鉴、结局画廊。

### 8.4 开放入队系统（金群侠传式自由结伴）

**设计原则**：不设固定"官方队友名单"。新海市所有**具战斗能力的具名 NPC**（学生、管理局职员、互助会成员、独立散人——原卡世界观中觉醒者本就是"公民+战力"双重身份）均可邀约入队，**只做数值与关系门槛，不做人物限制**。

**通用入队门槛（双条件同时满足）**：

| 条件 | 规则 | 设计意图 |
|---|---|---|
| 好感度 | **≥ 20**（初识期满，进入熟悉期） | 关系先于组队——你得先认识这个人 |
| 等级匹配 | **NPC 等级与主角等级差 ≤ 2 级**（高或低都算） | ①防前期白嫖高战力；②防后期虐菜感；③等级门槛天然随主角成长动态解锁新伙伴——把"练级"变成"解锁人" |

- **邀请交互**：好感 ≥20 且等级差达标时，对话出现【邀请同行】选项；NPC 有自身日程（上课/任务/驻守），当周行程冲突会拒绝（改约下周）；
- **队伍规模**：主角 + 3 名同伴；同伴可随时在据点轮换；
- **剧情强制情形（唯一例外，白名单制）**：
  - **强制队友**：主线节点指定的剧情队友，无视好感与等级门槛临时入队；
  - **强制缺席**：剧情需要某角色离队/敌对时，即使好感满也会离队；
  - **客串强力队友**：楚南星（S 级天才榜第一）幕间客串 1-2 次（限时体验高等级战力，爽点设计）——不满足等级差，故只能以剧情形式登场，恰好自洽；
- **不可入队角色**（世界观自洽，非名单限制）：渊蚀会敌对状态者（除非走特定策反剧情线转为可入队，作为剧情奖励）、纯设定级大人物（院长/家主，日程不允许）；
- **队友成长**：入队 NPC 同样拥有觉醒度/突破/熟练度系统，随出战积累（练谁全由玩家决定，二周目价值来源之一）；
- **入队剧情钩子**：每位可入队 NPC 保留 1 条个人支线（信任期 51+ 触发）与至诚期结局分支——开放入队不等于砍掉角色深度，只是把"谁成为核心伙伴"的选择权交给玩家。

| **世界层** | **960×540**（构图基准） | 场景、角色、战斗小人、技能特效 | 纹理过滤 nearest、2D 像素吸附、整数缩放（×2=1080p / ×4=4K 完美对齐）；窗口尺寸不整除时调整世界可见范围，填满客户区；48×48 角色的基础占比约为屏高 9%，首章近景比例另见实施补充 |

- **场景**：现代都市六区各有主色调（学院区暖白、CBD 霓虹、旧城赛博昏黄、裂隙内紫调+2D 光照）；tileset 模块化复用（同素材换调色板出不同区域氛围，压产能）；

- **2026-09-30 分辨率适配补充**：窗口、最大化和 F11 全屏均使用完整客户区。整数倍率只应用于像素世界，不再限制整个应用；非标准尺寸通过扩展/裁切可见范围适配，UI 以实际客户区重新布局。具体首章实现与测试见《第1章可玩流程实施补充》。
- 逸剑风云决式"复古但精致"的整体气质不变。
- **2026-10-18用户指定的对话立绘扩充**：当前三份运行台词中的33个发言身份均配独立2D人物立绘，人物对话在UI右下角显示；探索与战斗继续使用原像素小人。画风为现代都市服装的精细国风RPG立绘，完整范围、资源与布局见《人物对话立绘实施补充》。本项覆盖下表原先仅8~10张立绘及超额NPC只用文字介绍的对话美术限制，其他美术预算保留。

> 弃用方案备忘：640×360 全像素（角色占比 13% 偏大、中文 UI 拥挤）——若后续想极致复古可再评估，当前不做。

### 10.2 全自制美术产能策略（硬预算）

| 资产 | 预算上限 | 说明 |
|---|---|---|
| 活跃 NPC（有对话立绘/像素头像） | 20 名 | 超出者用通用模板像素小人+文字介绍 |
| **可入队战斗小人** | **≤14 名** | 与活跃 NPC 共用像素小人资产，战斗帧（待机/攻击/受击/技能/倒地）为增量；特效按五系做 5 套色彩参数模板 |
| 全身立绘 | 8~10 张 | 仅主角+核心剧情角色+最终 BOSS；其余用像素头像+对话框 |
| CG 插画 | ≤8 张 | 仅三幕高潮节点；其余用像素演出+镜头语言替代 |
| 技能特效 | 逐帧 ≤20 个 | 其余用 Shader+粒子系统组合生成 |
| 场景 tileset | 6 套 | 六区各 1 套，裂隙地形用 1 套紫调 tile 换色复用 |
| 中文点阵字体 | 1 套 | Fusion Pixel Font 等开源像素中文字体（开放授权），UI 层 1080p 渲染用 |

- 风格化降精度：受限调色板（每区 16~32 色），弱点变风格；
- 立绘可用"半身像+描边"风格降低绘制成本；
- **v0.4 补充（个人项目弹性）**：预算表是"质量下限"而非"商业交付标准"——vibe coding 迭代中允许用占位素材先跑通玩法，美术后置换皮，避免"美术没画完→玩法没得测"的顺序陷阱。

### 10.3 战斗演出与音频

- **战斗演出**：指令选择 + 技能特写镜头 + 突破/失控全屏演出（Shader：扭曲/色散）；
- **音乐**：都市轻爵士（日常）→ 交响摇滚（战斗）→ 氛围电子（裂隙）；每区一主题；个人项目建议优先用 CC0/免费授权曲库起步（非商用许可宽松），后期有执念再自制替换。

## 11. Godot 技术方案

### 11.1 版本与架构

- Godot 4.3+（GDScript 为主，vibe coding 与 AI 辅助迭代友好；战斗公式热点后续可优化）；
- 顶层场景流：`Boot → Title → Overworld(城市/区域) ↔ Battle ↔ UI 覆盖层`；
- **渲染架构（v0.4.2，2026-09-30 补充分辨率适配）**：世界层以 960×540 为构图基准（纹理过滤 nearest、2D 像素吸附、整数缩放，实际视口随窗口可见范围调整）+ UI 层 CanvasLayer 以 1920×1080 为布局基准（独立等比缩放与边缘锚定，字体矢量渲染）。首章运行时取消根窗口整体拉伸，让两层分别适配客户区；保留 M0/M1 开发入口原设置；探索场景俯视 2D；
- 战斗场景：回合状态机（`ROUND_START → COMMAND → EXECUTE → ROUND_END`）+ 角色节点池 + 演出队列（技能/连携/突破统一走演出指令队列，保证手感一致）；
- **开放入队技术要点**：同伴 = 数据驱动的通用 Combatant 实例，入队 NPC 复用敌人/通用战斗节点，只挂不同的属性表+技能表+动画帧集——新增可入队角色 = 新增一份 Resource 数据，零代码改动；
- **资源精简的技术红利（v0.4）**：删除 MP 后，Combatant 状态机少一条资源流、UI 少一个条、配表少一列——对个人 vibe coding 项目，每删一个系统都是实打实的工期节省与 bug 面缩减。

### 11.2 数据驱动（策划可独立配表）

- 技能 / 敌人 / NPC（含好感/等级/系别/可入队标记）/ 掉落 / 事件 / 对话 / 商店 / 任务全部 `Resource(.tres)` 或 JSON 外置；
- 日程系统核心 = **日历调度器**（Calendar Scheduler）：日期推进 → 触发节点表（年度节点/周结算/任务板刷新/事件池/NPC 周程），是全项目的脊椎模块，最先做；
- 存档：字典序列化 JSON（含日历状态、好感矩阵、声望、背包、世界标志位、入队状态）。
