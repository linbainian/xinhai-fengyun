# M1-A 战斗灰盒实施补充

日期：2026-09-30。适用范围：M1 的第一批独立 1 对 1 沙盒。以下是依照 [M1 开发计划](../Game/docs/M1开发计划.md) A 批建议落地的**原型默认口径**，可根据试玩反馈调整；不代表正式第1章角色或敌人配表已经定稿。

## 本批启用的规则

| 项目 | 实施口径 |
|---|---|
| 一轮 / 一次行动 | 一轮让双方存活单位按 SPD 各行动一次；攻击或防御占该角色一次行动；下一轮重新排序 |
| 同速 | 双方各掷 1d6，高者先动；同点重掷，全部骰点进入日志 |
| 普攻 | 按策划 §5.4 结构，倍率 ×1，伤害波动 2d10；普攻不增加 SL |
| 命中 | 基础命中 + 感知差 ×2 − 目标闪避，限制在 0–100%；0% 必未命中，100% 必命中 |
| 伤害 | 公式各项计算后统一四舍五入；成功命中最低 1；HP 最低 0；未命中伤害为 0 |
| 防御 | 回复 HP 上限的 10%，四舍五入并封顶；SL -15，最低 0；本批没有额外减伤效果 |
| 初始状态 | HP/SL 从遭遇表读取；初始 HP=-1 表示满血，正值封顶到 HP 上限，SL 限制在 0–100 |
| 倒地与胜败 | HP=0 倒地；本次演出结束即判胜败，倒地单位不执行尚未轮到的行动 |
| 重试 | 重新加载遭遇及所引用的单位/规则表，恢复开场 HP/SL、轮次、种子与日志；停止旧 Timer 和 Tween |
| 随机复现 | 同引擎版本、同配表、同种子、同一合法指令序列得到同样的日志；非法/重复指令不消耗随机数 |

克制、等级压制和环境修正本批固定 ×1；加载时拒绝非中性修正与不同等级的遭遇。SL 暂时只呈现与防御回落，阈值惩罚/失控、技能/CD、临界槽/突破分别在 M1-B/C 接入，不能把本批视为完整 M1。

## 灰盒测试配表

| 数据 | 测试新生 | 测试敌人 |
|---|---:|---:|
| 等级 / 系别 | D / 强化 | D / 强化 |
| 六维 | 全部 10 | PER=8，其余 10 |
| HP 上限 | 120 | 110 |
| 开场 HP | 90 | 110 |
| 开场 SL | 30 | 0 |
| 攻击 / 防御 | 20 / 12 | 16 / 12 |
| SPD | 14 | 11 |
| 基础命中 / 闪避 | 96% / 3% | 96% / 4% |

六维到派生战斗属性的映射仍待设计；本批攻击、防御、SPD 等直接配表，只有 PER 依既定公式参与命中。开场伤势与 SL 用于观察防御，不是正式剧情开场。

默认种子为 220101，遭遇版本 `m1-a.1`。敌方只执行普攻。数值入口位于 `Game/data/battle/m1_a_*.tres`，需要修改测试系数时同时更新数据版本并记录到验收文档。演出与敌方等待时长也在规则表中，可独立调整。

## 交付与日志

独立运行 `Game/scenes/battle/battle_sandbox.tscn`。F5 仍运行 M0；选中战斗场景后 F6 运行本批。战斗界面支持鼠标按钮和 A 攻击 / D 防御 / R 重试 / E 导出 / F11 全屏。

日志保存到 Godot 的 `user://battle_logs/`。日志含开场配表快照、规则版本、随机种子、行动顺序与同速骰、每次命中抽样/伤害骰/修正、结算前后 HP/SL，以及最终结果。也可在战斗过程中导出，文件会标明当时阶段，未完成战斗的结果为空。

M1-B/C/D 的建议仍以 M1 开发计划第5节为待确认事项；本补充只收敛 A 批，不预先决定后续规则。
