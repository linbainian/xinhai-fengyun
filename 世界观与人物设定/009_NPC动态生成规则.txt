# NPC动态生成规则（路人觉醒者生成）
# 对标道渊[0] NPC人物生成规则

trigger: |
 当叙事需要生成非关键角色（路人、小怪、普通觉醒者、普通市民）时，强制触发本机制。
 关键人物（已定义角色，见各角色条目）不在此列，直接调用其条目。

generation_rules:

 identity_distribution:
  场景权重: 普通城区/居民区/商业街等日常场景按「普通市民92%/E级5%/D级2%/C级0.8%/B级0.2%/A级0%」生成——这是"主角能碰上谁"的遭遇加权，不是人口分布（人口分布见「觉醒者等级体系」：觉醒者仅占0.3%、F级占99.7%）；学院/裂隙/黑市/擂台/管理局等觉醒者聚集场景使用下表
  普通市民: 35%（F级大众，微异能聊胜于无，被卷入异能事件的普通人）
  E级觉醒者: 25%（萌新/日常工作者）
  D级觉醒者: 20%（稳定期/安保快递医护）
  C级觉醒者: 12%（实战级/职业赏金猎人）
  B级觉醒者: 6%（精英级/管理局基层）
  A级觉醒者: 2%（高手级，少见于日常）

 faction_distribution:
  基准（无场景修正时）:
   无阵营: 40%（普通市民或独立觉醒者）
   管理局登记: 30%（在册觉醒者）
   学院学生: 15%（年轻觉醒者）
   互助会挂靠: 10%（灰色地带）
   家族旁支: 3%
   渊蚀会喽啰: 2%（仅在反派场景）
  场景加权（命中场景时整表按此重分配，不再用基准）:
   学院区/校园: 学院学生55% / 管理局登记15% / 无阵营20% / 互助会挂靠5% / 家族旁支5%
   管理局·裂隙前线: 管理局登记60% / 无阵营20% / 学院学生10% / 互助会挂靠5% / 家族旁支5%
   旧城区·港口·黑市·擂台: 无阵营35% / 互助会挂靠25% / 管理局登记20% / 家族旁支10% / 渊蚀会喽啰10%
   龙湾富人区·商业街: 无阵营45% / 家族旁支20% / 管理局登记20% / 学院学生10% / 互助会挂靠5%
  阶段加权（叠加在场景之上）:
   学院篇: 学院学生与管理局登记各 +5%，其余等比下调（开局即学院篇，无前置阶段）
   暗流篇: 互助会挂靠与家族旁支各 +5%，渊蚀会喽啰上限放宽到 8%
   真相篇: 渊蚀会喽啰与互助会挂靠各 +5%，允许出现渊蚀会正式成员（非喽啰）
  规则：加权结果在正文里必须不可见——体感是"那个地方本来就该有这些人"，禁止解说人口结构。
  新势力入场后，由「势力遭遇索引」同步在本表补一行份额。

 ability_system:
  系别: 念动力系30% / 元素系30% / 强化系25% / 精神系10% / 特殊系5%
  分配: 与主角等级对比——
   高于主角一个大级: 5%（少见强者）
   与主角同级±1: 30%
   低于主角: 65%（路人为主）

 personality_library:
  pool: [贪婪, 谨慎, 傲慢, 怯懦, 忠诚, 热血, 阴险, 淡泊, 投机, 话痨, 高冷, 八卦, 市侩, 正义, 圆滑]
  pick: 选1-2项组合，推导行为
  examples:
   - 贪婪+赏金猎人 → 见利忘义，可能反水
   - 谨慎+市民 → 第一时间逃跑报警
   - 八卦+学院学生 → 拍照发朋友圈/直播

 naming:
  姓氏: 百家姓常见（李/王/张/刘/陈/杨/赵/黄/周/吴/徐/孙/朱/马/胡/郭/林/何/高/罗/郑）
  名字: 现代常用双字名（避免古风违和）
  例: 李昊/王小满/张雨晴/刘子轩/陈一一
  觉醒者代号: C级以上可有代号（如「快刀」/「铁壁」/「千眼」）

 behavior_logic:
  principle: 基于「环境→阵营→性格→实力差」综合判断
  examples:
   - 普通市民目击异能战斗 → 惊恐+拍照+报警+逃跑（顺序看性格）
   - 觉醒者路人遇主角展露稀有异能 → 贪婪者觊觎/谨慎者远离/投机者结交
   - 觉醒者路人遇危机 → 向在场最高等级者求救
  diversity: 禁止反应雷同，必须有性格差异

 interaction_with_protagonist: |
  路人NPC不进入「人物」变量（除非发生重要互动被AI提升为次要NPC）。
  重要互动（救命/结仇/合作）后，AI可将其注册为「人物」变量并补充信息。
