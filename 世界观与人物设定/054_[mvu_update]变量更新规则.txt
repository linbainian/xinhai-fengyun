# 变量更新规则

update_rules:

 # ===== 世界变量 =====
 世界.叙事回合:
  type: number
  check: 每次正式进入世界内叙事的AI回复+1。初始为0；首个剧情回复写为1。纯OOC、规则解释、纠错或重生成不代表世界内新回合，不得据此让时间、遭遇或事件重复结算。

 世界.当前时间:
  type: string
  format: 觉醒历X年MM月DD日 HH:MM
  check: |
   **唯一时钟**。事件推进、休息、旅行、章节转场或玩家要求快进之后，直接写出新的绝对时间——照格式写数字，不要手算分钟、不要写相对表述。
   Zod 会按本字段反算「累计分钟」并规范化格式；写成非规范格式（如「今天」「三天后」）或早于起点的值，该回合推进作废、保留上一次的值；漏写「觉醒历」前缀的宽松写法（如「22年1月2日 8:00」）会被规范化补全，不算无效。禁止模糊时间、禁止倒退、禁止用现实历法（节假日/节气/星期）填空。

 世界.累计分钟:
  type: number
  range: 0~
  check: |
   派生量——由「世界.当前时间」换算而来（起点觉醒历22年01月01日08:00为0）。**不得反向当时钟**：不要为了改时间去改它，也不必手算。
   仅用于 NPC 成长锚点与时间跨度门槛等分钟级计算。禁止重复计算并行活动或同一场景。连续3个叙事回合「世界.当前时间」均未推进时，必须按「时间设定」给出一次自然跳时——世界时钟不允许无限期停摆。

 世界.本回合耗时:
  type: number
  range: 0~
  check: |
   仅作记录（本回合流逝的分钟数），可写0或省略；**不参与时钟推导**，写错也不影响时间。禁止用它反推当前时间。
   手感参考：即时回答/观察/内心/OOC=0；连续对话5~30；短动作1~5；战斗1~10；院内移动5~20；城区移动20~90；听课/集会45~120。长跳时在正文说明睡眠、修炼、任务过程、闭关或章节转场。

 世界.上次时间更新回合:
  type: number
  range: 0~
  check: 每个正式叙事回合核对时间后写为本回合「世界.叙事回合」。若已经等于本回合，禁止再次推进时间（防止同一回合重复结算）。

 世界.上次日结算日期:
  type: string
  format: 觉醒历X年MM月DD日
  check: 当前时间的日期部分与本值不同时，跨日重置「主角.今日结晶使用」和「主角.药剂耐受」一次，再写入新日期；同一日期不得重复重置。

 世界.上次周结算累计分钟:
  type: number
  range: 0~
  check: 周周期的锚点（本世界**没有星期**，周＝每7天，锚在累计分钟上）。仅当「累计分钟-上次周结算累计分钟≥10080」时重置「主角.本周任务完成」一次，并把本值推进「已结算周数×10080」（保留不足7天的余数）；同一区间不得重复重置。

 世界.上次NPC结算累计分钟:
  type: number
  range: 0~
  check: NPC日成长的结算锚点。仅当「累计分钟-上次NPC结算累计分钟≥1440」时结算完整天数；结算后增加「已结算天数×1440」（**单次上限30天**），保留不足一天的余数，禁止直接按回合数虚构天数。

 世界.已触发日历节点:
  type: z.record
  check: |
   节点ID对应对象{状态, 时间, 结果}。状态仅为[已预热/已触发/已结算]。对象里的「时间」记录的是预热/触发/结算**发生的那一刻**；判断节点是否跨过时，用的是该节点ID在「学年大事历」节点表里的**表定时间**，不要拿本字段比较。
   凡「节点时间 ≤ 世界.当前时间」且状态尚未触发/结算的节点，一律视为已跨过并推进状态；同一节点的事件、奖励、榜单、任务与结算只执行一次。时间只进不退，因此无需旧时间；一次长跳跨过的多个节点必须全部补齐。
   **起点规则（关键）**：起点＝觉醒历22年01月01日 08:00（**入学日当天**）。起点之前不存在任何学院节点——「世界.已触发日历节点」开局为空，没有需要补记录、补触发、补结算的旧节点，也没有可以当背景引用的"上学期"；AI 不得虚构"起点前学院里已经发生过"的任何事（往届拜山、已加入的社团、已经考过的考核一概不存在）。

 世界.当前地点:
  type: string
  check: 主角移动时更新，含具体地点和环境描述

 世界.天气:
  type: string
  check: 时间推进半天以上时可能变化，影响灵能浓度和异能

 世界.灵能浓度:
  type: number
  range: 0-100
  check: |
   根据地点详细设定（详见「灵能浓度详解」条目）：
   0~19灵能荒漠(恢复×0.3/无法修炼)/20~39低灵能(恢复×0.7)/40~59普通(恢复×1.0)/60~79高灵能(恢复×1.5/修炼+50%)/80~100灵能富集(恢复×2/修炼翻倍/危险)
   地点映射：市区45-55/学院修炼塔40-85（按层递增，常用层65-75）/裂隙70-100/苏家庄园60-70/旧城区25-35

 世界.危机程度:
  type: string
  check: 根据当前事件评级（无/低/中/高/极高）

 世界.遭遇冷却:
  type: number
  range: 0-6
  check: 每回合强制-1，归零时触发遭遇事件后重置6。首回合若为0必须立即结算一次遭遇（见「主线事件表」「机遇与代价机制」），不得静默跳过

 世界.动向:
  type: z.record
  check: |
   常态=2条、上限=2条。每回合检查两个槽位。禁止为制造变化伪造时间门槛，但同一槽位在同一阶段停留不得超过3个叙事回合——到限必须推进一级，或按「合」收束并在下回合换新「起」（回合上限优先于时间门槛）。
   阶段只允许起→承→转→合；同时满足「当前时间≥最早推进时间」与「推进条件已在正文或世界侧成立」时才推进一级。禁止跳阶段、倒退或为制造变化虚构时间。
   开局为空时一次性add两条互不重复的起阶段事件；若回合开始时某槽为合，则先兑现合阶段结果，再remove旧标题并add全新起事件，新事件当回合不得推进到承。
   每条对象字段：阶段/类型/来源/地点/参与者/当前压力/下一步/最后推进回合/最后推进时间/最早推进时间/推进条件/描述。只有阶段真正变化时，最后推进回合与最后推进时间才改为本回合值。
   创建或推进阶段后必须给出下一阶段的精确最早推进时间和具体因果条件。参考最小刻度：现场小事件15~60分钟、校内/街区事件1~3小时、全城事件3~12小时、跨城/全国事件1天以上；事件本身可要求更久。
   未到刻度时允许更新当前压力/下一步或通过新闻、群聊、传闻、报告给出可观察变化，但不得把改写描述冒充阶段推进。剧情防停滞由NPC行动、消息、遭遇和现场变化共同承担；但连续3个叙事回合两槽阶段均未变化即为停摆，必须推进其一。且每回合至少一条动向必须能被主角在当前场景直接感知——若两条都与现场无关，必须以人上门/通讯/求助/指名委托等直接方式让其中一条接触主角，不得两条都只走新闻。
   描述随阶段加深且≥50字；主线事件链优先占一格，另一格从最近学年节点/NPC下一行动/势力行动（势力名取「主线事件表」的阶段分级清单）/遭遇余波中产生。与现场无关的动向不得强迫主角转场；绝不超过2条。
   入槽算法（优先级 主线>大凶>大吉>普通）：①某槽阶段=合→新链直接入该槽；②否则高优先级链抢占最低优先级非「合」链，被抢占链当回合按「合」结算收束（结果写入对应变量/叙事，不算丢失）；③同一势力/同一线索的新链并入旧链（保留更后阶段，另一条按「合」结算）；④禁止第3条，排队信息写入现链的「下一步」，槽位空出后按优先级补入

 主角.觉醒度:
  type: number
  range: 0-100
  check: |
   觉醒度=经验值（0-100）。已达100时后续修炼不再增加（保持100），积累不溢出也不归零，直到突破执行后才归零。：
   - 日常修炼/冥想（等级递减制）：E~C级 +2~3/回合，B~A级 +1~2/回合，S级 +1/回合，SS级 +0.5~1/回合
   - 参与战斗/使用异能 +3~6/回合（实战经验加成——对手越强越多）
   - 高灵能区(≥60)加成 ×1.5
   - 灵能富集区(≥80)加成 ×2.0
   - 导师指导加成（按等级递减：E~C级+3~5，B~A级+2~3，S级以上+0.5~1；NPC在场时）
   - 完成重要事件/任务 +5~15（AI根据剧情判断）
   - 「新手红利」：大一学年内且觉醒等级≤C级时生效（每学年首月另+50%效率，详见「修炼与提升」条目），觉醒度<20时前5次修炼获得×2加成
   - 使用修炼资源（药剂/结晶）：按「修炼资源图鉴」条目数值一次性加成（聚能药剂一次修炼×1.5、结晶+5~20——S级以上结晶减半等）
   - 连续修炼（每回合都修炼）+1累计加成（上限按等级递减：E~C级最多+3、B~A级最多+2、S级以上最多+0.5）
   - 长期不用（超过5回合未修炼）-1/回合
   - 突破前兆：觉醒度≥85时必须在叙事中描写前兆征兆（85~89轻微、90+明显——异能波动/灵能涌动/感知锐化）
   - 突破临界：觉醒度=100时进入临界状态，可在任何场景触发突破：
    - 安全环境→正常触发突破判定
    - 战斗中→可直接临阵突破（爽点），成功率基础-10%（战斗分心）。若生命<30（生死一线），改为+10%（置之死地而后生，替换-10%而非叠加）。精神负荷额外+15
   - 突破后归零：不论成败，觉醒度重置（成功→0，失败→50~75）
