# 主线事件表（剧情推进度=100时掷2d6触发）

trigger: 世界.剧情推进度达到100时
mechanism: 以本回合注入的主线骰查表（AI 不得自行掷骰或改写）——主线骰: {{roll:2d6}}，AI在叙事中自然融入
stage_gate: 先查「主线阶段（幕结构）」条目——当前阶段不可用的事件必须顺延重掷（结果+1循环至可用）。12号发放的碎片编号受阶段上限约束，且必须从「觉醒潮真相·天机」条目按序取材，写入 世界.真相碎片 数组

events:
 2: 世界异变——觉醒潮异常（极光重现/灵能浓度全城骤升/天榜前三异动）
 3: 深渊回响——姜无咎传话/夜阑珊梦中警告/深渊气息渗入学院
 4: 学院危机·内——教职或学生失踪/禁区封印松动/内鬼暴露
 5: 势力摩擦——管理局与互助会在旧城区对峙/执法越界
 6: 家族暗涌——古血脉家族联盟内部政变/联姻要挟/族中子弟冲突
 7: 裂隙爆发——学院周边出现中型裂隙/异兽突入城区
 8: 悬赏升级——榜上通缉犯在学院区现身/新增高危悬赏
 9: 管理局行动——大规模搜查/抓捕行动波及学院/特招生被征召
 10: 渊蚀会渗透——发现渊蚀会在学院附近活动的痕迹/失踪案与渊蚀会有关
 11: 天才碰撞——天才榜排名变动引发公开挑战/跨阵营切磋/楚南星出手
 12: 觉醒潮真相碎片——按「觉醒潮真相·天机」的发放表按序给出下一块碎片，来源人物须符合 who_knows_what（极稀有·推主线）

# ===== 事件链机制（主线事件不再是一次性的） =====
event_chains:
 principle: |
  每个主线事件触发时，不是打完即弃——必须作为一条「事件链」注册进「世界.动向」变量
  （阶段=起，类型=主线事件链，地点/描述按事件内容填写），同时设置最后推进时间、最早推进时间与推进条件；随后按世界时间和因果条件沿「起→承→转→合」推进，而不是按回复次数推进；若同一动向阶段已停留满3个叙事回合，则本回合必须推进（见 dual_trend_engine）。
   动向栏常态且最多维持2个并发大事件——主线事件链占其中一格，优先级最高。
 chain_hooks:
  2_世界异变: 起:异常现象被观测 → 承:管理局封锁消息/学者争论 → 转:异常扩散并迫使强者选边 → 合:天榜强者介入或真相碎片浮出（可衔接12号事件）
  3_深渊回响: 起:低语/梦境警告 → 承:接触者出现（牧遥/夜阑珊）→ 转:回响诱发一次现实代价或真假难辨的选择 → 合:主角获得深渊线索或精神负荷代价
  4_学院危机内: 起:失踪/异动被发现 → 承:内部排查（怀疑气氛/苏怀舟压场）→ 转:证据反转或危机在校内爆发 → 合:内鬼暴露或封印加固
  5_势力摩擦: 起:对峙事件 → 承:双方拉拢中间人（主角可能被卷入）→ 转:误判/泄密令摩擦公开升级 → 合:和解/结仇，舆论风向变化
  6_家族暗涌: 起:联姻/政变风声 → 承:族中子弟冲突表面化（苏晚棠/白沐瑶卷入）→ 转:旧盟约或血脉证据改变站队 → 合:格局变动并留下关系机会与代价
  7_裂隙爆发: 起:裂隙出现/封锁 → 承:探索或清剿（掉落材料入储物栏）→ 转:裂隙结构突变/异兽越界 → 合:关闭裂隙或承担异兽入城余波
  8_悬赏升级: 起:通缉犯现身 → 承:追捕线索链（黑市/情报贩子）→ 转:猎人与猎物身份反转或第三方截胡 → 合:捕获领赏或结仇逃逸
  9_管理局行动: 起:搜查开始 → 承:主角被征召或被怀疑 → 转:行动目标/命令暴露矛盾 → 合:行动落幕，档案状态可能变化
  10_渊蚀会渗透: 起:渗透痕迹 → 承:失踪案调查（牧遥的影子）→ 转:诱饵引爆或潜伏者反咬 → 合:挫败阴谋或埋下更深伏笔
  11_天才碰撞: 起:排名异动/挑战书 → 承:公开切磋（可押注）→ 转:规则变更/隐藏实力/场外压力打破预期 → 合:排名更新，形成新的对手或朋友
  12_真相碎片: 链外单发线索——不单独注册或占用「世界.动向」槽位；挂靠当前最相关事件链的本阶段描述，或通过$系统提示/任务线索发放，并在后续2~3条事件链中回响。不得因此创建第3条动向，也不得让被挂靠链额外跳阶段
 resolution: 事件链到「合」阶段结束后，从动向栏移除。跨链呼应（如10号链的伏笔在4号链引爆）是最高级的叙事——鼓励但不强制。

dual_trend_engine:
 principle: |
  「世界.动向」是两个固定槽位的世界事件发动机，常态=2、上限=2。每回合检查两个槽位，但回复次数不等于事件时间：
  - 只有「当前时间≥最早推进时间」且「推进条件已经成立」时，才允许起→承、承→转、转→合推进一级；禁止跳级、倒退或伪造时间门槛。
  - 阶段真正变化时才更新最后推进回合/最后推进时间，并为下一阶段写入新的精确最早推进时间与推进条件。参考最小刻度：现场小事件15~60分钟、校内/街区1~3小时、全城3~12小时、跨城/全国1天以上。
  - 未达到门槛时可以通过NPC行动、新闻、传闻、报告、压力变化或下一步变化表现世界在动，但不得修改阶段冒充推进；单一槽位允许偶有一回合不改阶段，但同一阶段停留不得超过3个叙事回合——到限必须推进一级，或按「合」收束并在下回合换新「起」。
  - 当前为合→当回合remove旧标题并add一个全新标题的新事件，阶段=起；新事件当回合不得再推进到承。
  - 开局动向为空时，一次性生成两条随机且互不重复的起阶段事件，视为两个槽位本回合的变化。
  主线链优先占槽；另一槽从最近学年节点/NPC下一行动/势力行动/命运骰余波中选。不得为塞新事件而创建第3条。
    势力行动可选清单（按主线阶段分级取用；同一势力不得连续两次占同一槽位）:
     学院篇: 学院内部 / 异能管理局（考核部·驻校联络官·执行部与情报部） / 古血脉家族联盟 / 黑市 / 异能科研院所 / 觉醒者医疗与收容机构 / 觉醒者产业与资本 / 媒体集团与舆论机构 / 赏金猎人与佣兵体系 / 地下竞技与赌盘 / 国际异能体系（驻校海外交换生） / 其它院校 / 市井与非觉醒者社会 / 凡人议会 / 独立散人与民间觉醒者 / 异兽　（开局即学院篇，本行即起步可用清单——与「势力遭遇索引」各势力「学院篇／全阶段」档位逐项对齐）
      围观级（学院篇只可用作「可旁观」：主角能看到其行动或成果，但不发生互动）：暮光互助会（学院篇内不发生互动）；渊蚀会为「可旁观 ＋ 唯一一次低强度正面冲突」——洪九地盘外围／传道人／低语，不得接触核心层、不得升级为据点战，这正是学院篇→暗流篇推进条件所需的「一次渊蚀会正面冲突」（档位以「势力遭遇索引」为准）
     暗流篇: 上述全部（暮光互助会／渊蚀会由「围观级」升级为可直接接触）＋ 家族内部倾轧 / 渊蚀会核心层的渗透动线 / 国际异能体系深化（交换项目、邀请赛、外网舆论战）
     真相篇: 上述全部 + 渊蚀会核心层 / 觉醒潮真相相关方
    新增势力由「势力遭遇索引」条目同步补进对应阶段；不得使用清单与索引之外的势力名。
  入槽算法（优先级 主线>大凶>大吉>普通）：①某槽阶段=合→新链直接入该槽；②否则高优先级链抢占最低优先级非「合」链，被抢占链当回合直接收束（按「合」结算结果并随即移除，结果写入对应变量/叙事，不算丢失；不计作阶段性推进、不写推进时间门槛）；③同一势力/同一线索的新链并入旧链（保留更后阶段，另一条按「合」结算）；④排队信息写入现链的「下一步」，槽位空出后按优先级补入。
 visibility: |
  每回合只把与当前场景相关的一条动向直接写进现场；远方动向用新闻、传闻、报告、榜单或通讯露出，不得强行把主角传送到事发地。若两条动向都与主角当前场景无关，必须让其中一条以直接方式接触主角（有人上门、直接通讯、指名委托、当面求助），不得两条都只走新闻。
  动向描述必须写清本阶段新变化、参与者压力与下一步，不能只是换措辞；每条描述不少于50字。

event_variants:
 principle: |
  2d6结果决定事件「类别」，但每次触发必须从下方修饰池随机组合「地点/规模/势力/反派」填入事件描述，
  保证同类事件每次的地点/规模/反派都不同——同一组合至少间隔2次不重复。
 pools:
  地点: [学院区, 旧城区, 港口工业区, 龙湾富人区, 商业街, 市郊废弃工厂, 裂隙边缘, 管理局大楼周边, 黑市地下街, 海边]
  规模: [小范围（1~3人）, 中等（波及一个街区）, 大规模（全城关注）, 低调（无人注意但后患大）]
  势力: [管理局, 互助会, 渊蚀会, 家族联盟, 黑市, 独立散人, 异兽, 民间觉醒者, 学院内部, 其它院校, 国际势力, 产业资本, 媒体, 科研院所, 医疗收容, 赏金猎人, 地下竞技, 凡人议会]
  反派: [血鸦小队, 洪九的旧城帮派, 温蝉的传教线, 学院内鬼, 外来赏金猎人, 失控觉醒者, 裂隙异兽, 老牌通缉犯, 野生天才]
 usage: |
  触发主线事件时，用自由挑选或掷骰方式从修饰池组合填入事件链的描述与「世界.动向」注册内容。
  事件链推进时修饰元素应随阶段深化（起=端倪/承=卷入/转=爆发/合=余波）。

ai_guidance: |
 剧情推进度是行为驱动的（日常+5~8/修炼+8/任务+12~18/冒险+15~20/深度互动+15/战斗+20~25）。纯日常节奏下约13~20回合触发一次主线事件。
 2d6分布天然倾向7（裂隙爆发——最常见的日常级事件），两端（2和12）极稀有。
 事件严重程度应随故事推进自然升级——前3次偏日常，后续逐渐加重。
 到达100时优先处理——这比其他遭遇都重要。掷骰确定事件后剧情推进度归零；结果2~11按event_chains注册进「世界.动向」并持续到「合」，结果12按链外线索规则发放，不单独占槽。
 静止兜底（铁律）：连续6回合剧情推进度未增长，或连续3回合没有任何事件/人物接触落到主角眼前，AI 必须安排一次直接找上主角的事件——某人当面找来、通讯直接被点、求助贴到脸上、委托指名给主角（不是同届来信、舆论小浪这类远景）。世界在主角不行动时也在动，且必须动到主角眼前，不得让剧情静止
 固定骨架/动态过程：世界真相、主线阶段目标与阶段压力固定；事件的先后顺序、登场人物、进入路径、解决方法与结果由玩家选择和既有状态共同决定。不得把事件表演成唯一正确答案，也不得因玩家没点指定选项而停摆。

fragment_fallback: |
 真相碎片保底机制（防止主线被2.8%概率卡死）：
 - 计数器：写入「世界.真相保底计数」（number，持久变量——禁止用$系统提示承载）。每次主线事件触发，若结果≠12，计数器+1；若=12，重置为0。
 - 保底触发：计数器≥2时，本次主线事件无论掷出什么，强制按 12 号事件（觉醒潮真相碎片）处理——事件链「合」阶段结束时补发一块碎片（走 fragment_release_table 按序发放），计数器重置。
 - 阶段上限约束：保底补发同样受主线阶段碎片上限约束（学院篇限碎片1~2，暗流篇3~5，真相篇6）。
 - 通道C（被动兜底·防卡死）：学院篇内每完成2条主线事件链（推进到「合」并移除）而 世界.真相碎片 仍少于2块时，AI必须在当回合安排一次「线索主动找上门」——新闻露出/被删档案/匿名爆料/某人当面提起，按 fragment_release_table 按序发放下一块碎片。本通道只发碎片1~2，进入暗流篇后停用。
 - 通道B（调查）：除12号事件（通道A）外，玩家主动调查（对 who_knows_what 中列出的NPC，满足好感≥信任或完成其专属任务/剧情）可解锁碎片——详见「觉醒潮真相·天机」条目 fragment_second_channel。通道C（被动兜底）见本条目上方 fragment_fallback。
 - 目的：主线推进不依赖单一骰子结果，玩家调查与骰运并行，总有一条路能走通。
