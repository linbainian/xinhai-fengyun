# 势力遭遇索引（势力 → 具名成员 → 接触途径 → 阶段可及度）

# 用途：本表是「玩家能不能遇到学院以外的势力」的总接口。
# AI 每回合安排世界侧接触时，先查本表取势力名与具名人物。
# 与「NPC动态生成规则」的分工：本表管具名人物与势力级接触，生成规则管无名路人。

usage: |
 1) 每回合至少一次的「世界侧主动接触」，势力名必须取自本表或「主线事件表」的阶段分级清单。
 2) 同一势力的主动接触连续出现须间隔至少2个叙事回合，避免反复刷同一个势力。
 3) 校外场景遭遇优先用「常驻地点」，校内场景优先用标了「校园可达」的人物。
 4) 阶段可及度是**下限**不是上限：达到「可直接接触」后仍可继续深化，不必退回传闻。
 5) 随机池（[RANDOM_GIRL]/[RANDOM_STUDENT]/[RANDOM_VILLAIN]/[RANDOM_CITIZEN]/[RANDOM_OTHERSCHOOL]）按性别与角色编制、
   不按阵营编制——**本表就是这些池子的阵营过滤器**：抽出名字后必须回本表核对阵营，
   命中不匹配的当场换人，杜绝"学院池里抽出渊蚀会成员"这类错配。

可及度档位:
 传闻: 只在新闻/榜单/群聊/他人口中被提到，本人不出现
 可旁观: 主角能看到其行动或成果，但不发生互动（围观执法、看比赛、刷到直播）
 可直接接触: 主角能在场景中与其实名对话、被其委托，或被其主动找上门
 可合作: 可接其任务、建立长期关系、进入其内部
 敌对: 只以冲突形式出现

新增势力接入规范（今后新增势力一律往本表追加）:
 1) 势力条目必带两个字段——
    access_途径: 开局怎么遇到（必须具体到地点/人物/事件，禁止写"通过剧情发展"）
    阶段可及度: 三幕各自档位（学院篇／暗流篇／真相篇，取自上方五档）
 2) 本表追加一个「势力明细」区块：类型 / 常驻地点 / 校园可达 / 具名成员 / 随机池 / 阶段可及度
 3) 每势力尽量至少 1 名成员具备「校园可达」身份（学生／教职／常来学院区者）——这是可及性的首要保障；
   确实进不了校园的（渊蚀会／黑市／凡人议会等），改由「常驻地点 + 校外入口」保证可达
 4) 随机池优先为每势力建独占标签（如 [RANDOM_OTHERSCHOOL]）；暂未建独占池的沿用通用池，并在本表写明过滤规则
